# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, criticise ideas rather than people, and help newcomers. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@lokeshbothra21](https://github.com/lokeshbothra21), through a [private report](https://github.com/lokeshbothra21/aegisops/security/advisories/new) (it reaches only the maintainer; say it is a conduct report). Reports are handled confidentially.

The maintainer may remove comments, commits or issues that break this code, and may block repeat offenders, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
